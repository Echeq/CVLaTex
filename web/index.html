Guía rápida

Formulario: completa los campos de la izquierda. La previsualización se actualiza automáticamente mientras escribes.

Experiencia, educación, etc.: usa «Añadir» para crear más entradas y el botón ✕ para eliminarlas.

Editar: cambia el tamaño de la hoja, los márgenes o la fuente del documento.

CV de ejemplo: «Editar → Cargar CV de ejemplo» rellena el formulario con un ejemplo para ver cómo completar los campos.

Archivos: guarda tu CV como archivo CVLaTeX (.cvjson), expórtalo a PDF o a código LaTeX, o impórtalo.

Código LaTeX: desde «Previsualización → Ver código LaTeX» puedes ver y editar el código LaTeX generado. Al volver al formulario, el código se regenera desde los datos.

Exportar PDF: requiere un motor LaTeX (TinyTeX instalado automáticamente o MiKTeX/TeX Live).

Quick guide

Form: complete the fields on the left. The preview updates automatically while you type.

Experience, education, etc.: use “Add” to create more entries and the ✕ button to delete them.

Edit: change the paper size, margins or document font.

Sample CV: “Edit → Load sample CV” fills the form with an example so you can see how to complete the fields.

Files: save your CV as a CVLaTeX file (.cvjson), export it to PDF or LaTeX code, or import it.

LaTeX code: from “Edit → View LaTeX code” you can view and edit the generated LaTeX code. When you return to the form, the code is regenerated from the data.

Export PDF: requires a LaTeX engine (TinyTeX installed automatically, or MiKTeX/TeX Live).

CVLaTeX was born so that any university student can build their CV for free and portably, with no accounts, subscriptions or microtransactions: a comfortable editor that produces a standard-format CV and compiles it to a professional PDF, all on your own machine.
